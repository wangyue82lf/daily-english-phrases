## Week 1 (Jan 1-7)

### 2026-01-01: Get the ball rolling

**Meaning**: 开始做某事，启动某个项目或活动 (To start something, to set an activity in motion)

**Examples**:
- Let's get the ball rolling on this project. (让我们开始这个项目吧。)
- I think we should get the ball rolling before it's too late. (我觉得我们应该趁早开始。)
- Once we get the ball rolling, everything else will follow naturally. (一旦我们开始了，其他事情自然会顺利进行。)

**Notes**:
- 类似表达：kick off, start the ball rolling, set the wheels in motion
- 反义表达：put on hold, delay, postpone
