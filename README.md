# 📚 Daily English Phrases

> 每日英语短语学习记录

## 📖 项目简介

这是一个用于记录和复习每日学习英语短语的仓库。每天学习一个新的英语短语，通过例句和笔记加深理解。

## 📂 项目结构

```
daily-english-phrases/
├── README.md                    # 项目说明
├── phrases/                     # 短语记录
│   └── 2025/
│       └── 01-january.md        # 1月短语
└── review/                      # 复习记录
    └── weekly-review.md         # 周复习
```

## ✍️ 使用方法

### 每日添加新短语

在 `phrases/YYYY/MM-month.md` 文件中按以下格式添加：

```markdown
### YYYY-MM-DD: [短语名称]

**Meaning**: [中文释义]

**Examples**:

- [例句 1]
- [例句 2]

**Notes**: [学习笔记]

---
```

### 每周复习

在 `review/weekly-review.md` 中记录复习心得。
