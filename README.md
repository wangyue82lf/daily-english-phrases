## 📖 项目简介

这是一个用于记录和复习每日学习英语短语的仓库。通过持续的积累和复习，逐步提升英语表达能力。

## 📂 目录结构

```
daily-english-phrases/
├── README.md                    # 项目说明
├── phrases/                     # 短语记录
│   └── 2026/                   # 按年份组织
│       └── 01-january.md       # 每月一个文件
└── review/                      # 复习笔记
    └── weekly-review.md        # 周复习模板
```

## 🚀 快速开始

### 每日记录模板

```markdown
### YYYY-MM-DD: [短语名称]

**Meaning**: [中文释义] (English definition)

**Examples**:
- [例句 1] ([翻译])
- [例句 2] ([翻译])

**Notes**:
- 类似表达：[相关短语]
- 反义表达：[反义短语]

---
```

### 本地使用

```bash
# 克隆仓库
git clone https://github.com/wangyue82lf/daily-english-phrases.git
cd daily-english-phrases

# 添加新短语后提交
git add .
git commit -m "feat: add new phrase [短语名]"
git push
```

## 📝 使用方法

1. **每日学习**：每天学习 1 个新短语，记录到对应月份文件
2. **定期复习**：每周使用 `review/weekly-review.md` 进行复习
3. **实践应用**：尝试在日常对话或写作中使用新短语
